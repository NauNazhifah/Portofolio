02About The human / off duty & on record

Behind the dashboard.

The short version: I like hard questions, clean type, and making people say “oh — that's what the data meant.”

I make the complex feel obvious. Then I make it beautiful enough that people actually look.

I'm Naurah, a data analyst and interface designer based in Indonesia. My work sits between the query and the canvas: cleaning the messy middle, finding the one chart that matters, and shaping the little interface that gets it into someone's hands.

I've spent the past few years turning sales, mobility and public data into things people use — dashboards, visual essays, prototypes. I care about honest axes, accessible colour, and interfaces that explain themselves before you have to.

Off-screen: film photography, thrifted posters, and an ongoing search for the best pour-over in town.

03Process Raw → readable / repeatable, not rigid

The decode ritual.

A flexible four-step loop for turning questions into clarity. The order is intentional; the loops are inevitable.

  1. 01

    Gather

    Start with the decision, not the dataset. Interview, audit, and ask the annoying questions before touching a chart.

    Questions → sources
  2. 02

    Clean

    Tame the spreadsheets. Document every choice, because the tidiest dataset is still full of human decisions.

    Mess → method
  3. 03

    Decode

    Find the angle. Sketch ten versions, kill nine, and build the one visual logic that makes the point impossible to miss.

    Signal → story
  4. 04

    Deliver

    Ship it with a manual. A dashboard is only useful if someone else can explain it without you in the room.

    Clarity → handover

“Clarity is a feature,
not a finishing touch.”
